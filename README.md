# BRIGHT-TV
Overview
This project was completed as part of a BrightTV Viewership Analytics Case Study. The objective was to analyse BrightTV's user profiles and viewing behaviour to generate business insights that would help the Customer Value Management (CVM) team increase subscriptions and improve customer engagement.The dataset contains user profile information and TV viewing session data, where each record represents a single viewing session. The analysis focused on identifying viewing trends, customer behaviour, channel performance, peak viewing periods, and audience demographics to support data-driven business decisions.

The main objectives of this case study were to:
Analyse user and viewing trends.
Identify factors influencing TV content consumption.
Determine peak viewing periods and viewer behaviour.
Evaluate TV channel performance.
Recommend strategies to increase viewership and grow BrightTV's subscription base.

Tools Used
The following tools and technologies were used throughout this project:
Databricks SQL – Data querying, transformation and analysis
Databricks AI/BI Dashboards – Interactive dashboard development
PowerBI-Dashboard visualization
Looker Studio (Google Data Studio) – Dashboard visualisation
Microsoft Excel – Pivot tables, charts and supporting analysis
Git & GitHub – Version control and project management

Conclusion
This project demonstrates how data analytics can be used to transform raw viewing data into actionable business insights, by analysing customer behaviour, viewing trends, channel performance and audience demographics, the dashboard provides valuable information that can support BrightTV's Customer Value Management team in increasing customer engagement, improving content strategy and achieving subscription growth objectives.
